This code represents everything you should need to replicate all analyses in *SNT-TMS decouples the subgenual anterior cingulate cortex from the default mode network: A randomized controlled trial*

Code operates on neuroimages processed via [fmriprep](https://fmriprep.org/en/stable/) and [xcpd](https://xcp-d.readthedocs.io/en/latest/).

Code is divided into 4 sections: 1. Quality Control (QC), Non-negative matrix factorization for personalized functional networks (NMF), Functional connectivity derivation (FC), and Analyses. Scripts include comments throughout, and a comment at the top providing an overview of the role the script plays.

# QC
Automatic, framewise displacement-based QC does a lot of the lifting, but we also conducted manual quality control for this manuscript. 

This is largely achievable with the .html reports generated by xcpd and fmriprep, but we also used [ribbon_report.py](https://github.com/adpines/SNT_DMN-sgACC/blob/main/QC/ribbon_report.py) to evaluate freesurfer segmentations more thoroughly.

Framewise displacement was aggregated with [FD_aggregator.R](https://github.com/adpines/SNT_DMN-sgACC/blob/main/QC/FD_aggregator.R)

Respiratory traces (Figure 3) are also baked into here to avoid a separate section, even though respiratory tracing technically isn't QC. That script can be found [here](https://github.com/adpines/SNT_DMN-sgACC/blob/main/QC/plot_resp_intance.py).

# NMF
[Regularized NMF](https://pubmed.ncbi.nlm.nih.gov/28483721/) is a very established method at this point, for which [other](https://github.com/hmlicas/Collaborative_Brain_Decomposition/tree/6f3ad613d065fe592979e1f105065ed22472e999) [repositories](https://github.com/PennLINC/multiscale) [exist](https://github.com/ZaixuCui/pncSingleFuncParcel), but we've provided detail on the current implementation below for completeness. You'll need the first of these 3 repos downloaded and on your path.

The first step is just to downsample fslr-resolution images to fsaverage5. [This approach](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Step_0_DS_ts_fs5.sh) requires freesurfer and connectome workbench. I called it using a [simple sbatch script](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/sbatch_all_DS.sh) designed to submit each subjects' downsampling as a separate slurm job.

The [second step](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Step_1st_CreatePrepData.m) is create a small file that lets NMF know "where it is" in space. It doesn't impact the objective function too much relative to reconstruction error, but is a very nice adaptation of NMF to functional brain data. Only need to run once, not for each subject.

The [third step](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Step_2nd_ParcellationInitialize.m) is to run group-level NMF, which later serves as initialization for individualization. Outside of the massive human computation innate to running clinical trials, this is the most computationally intensive step of the whole project. Might take a few days to finish all the group-level estimates, depending on your compute setup. You will have a bad time if you try and run this locally. Use a compute cluster if you have one.

The [fourth step](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Step_3rd_SelRobustInit.m) is to pick out the most stable of the different group-level solutions. Runs pretty quickly (1-2 minutes).

The [fifth step](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Step_4th_IndividualParcel_AllSesh.m) is to actually derive the individualized parcellations. Again, use a compute cluster if you have one! This submits each subject as a separate job via sbatch.

If you so desire, [Mat_2_cifti.m](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Mat_2_cifti.m) and [Mat_2_cifti_ind.m](https://github.com/adpines/SNT_DMN-sgACC/blob/main/NMF/Mat_2_cifti_ind.m) can be used to convert these matrices to cifti files for visualization purposes.

# FC

OK, back to easy stuff. [Extract_FC.m](https://github.com/adpines/SNT_DMN-sgACC/blob/main/FC/Extract_FC.m) calculates correlations between the individualized default mode networks and the sgACC for each scan. Subject and session are also input arguments.

[AggFC.m](https://github.com/adpines/SNT_DMN-sgACC/blob/main/FC/AggFC.m) just aggregates the .csv files outputted from the previous step.

There's a separate script to get stim site - sgACC FC: it can be found [here](https://github.com/adpines/SNT_DMN-sgACC/blob/main/FC/EfieldSgACC_FC.m).

# Analyses

This section includes plotting and analyses, as they most often occur side-by-side in the code. 

The first script is just plotting out an alluvial format of our consort chart. That can be found in [this markdown](https://github.com/adpines/SNT_DMN-sgACC/blob/main/Analyses/Fig_S1_AlluvialConsort.md). For this and all other markdowns, I link to the .md file for ease-of-viewing, but the underlying .Rmd file is available in the same folder.

Brain plotting for figure 1 (panels C and D) can be found in [this matlab script](https://github.com/adpines/SNT_DMN-sgACC/blob/main/Analyses/Fig1.m). This script is very similar to that used for [figure S2](https://github.com/adpines/SNT_DMN-sgACC/blob/main/Analyses/FigS2.m), which plots classic discrete parcellations of personalized functional networks, and very similar to that used for [figure 2](https://github.com/adpines/SNT_DMN-sgACC/blob/main/Analyses/Fig2.m), which plots DMN-sgACC ROIs specifically.

But the majority of analysis/figure making is scripted in R. The code for figure 2 stats and visualizations is within [this markdown file](https://github.com/adpines/SNT_DMN-sgACC/blob/main/Analyses/Fig2.md).

The stats and visualizations for figure 3 are available in [this markdown](https://github.com/adpines/SNT_DMN-sgACC/blob/main/Analyses/Fig3.md).
